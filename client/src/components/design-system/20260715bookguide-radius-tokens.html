Radius Tokens

Four named steps. Each serves a different signal: sharper = data label, softer = container, considered = action, circle = signal point. Colour, position, and icons distinguish elements within a radius step — the radius itself distinguishes between classes of element.

1 · Primitive Scale
--radius-sm4px · fixed
All small labels — category chips, status badges, structural indicators. Colour and icons distinguish roles within this shape.

2 · Responsive Behaviour
Only --radius-lg scales, because only containers change size across breakpoints. Everything else is either too small for responsive radius to be perceptible or shape-defined.

--radius-sm 4px — no change — Fixed. Element doesn't resize.
--radius-lg 10px ↗ fluid 14px Fluid. Tracks card width.
--radius-button 12px — no change — Fixed. Shape = identity.
--radius-full 50% — always 50% — Fixed by definition.
The nav active pill resolves into --radius-full — 50% of its 30px height = 15px. It's a circle-family element that happens to live in an oblong container.
3 · Shape Language
The radius communicates what class of element you're looking at. Colour, icons, and position handle the distinctions within each class.
4px (sm) = "this is a label." Chips classify, badges state, indicators mark. A 六四 chip is red; a 可借閱 badge is green with a checkmark. Same radius, different signals carried by colour and icon.
10–14px (lg) = "this is a container." Something you browse, scroll, or tap into. The softness invites entry — you're looking at a place, not a label.
12px (button) = "this is an action." Considered, editorial, deliberate. Not bouncy or playful. The corner says "this matters" — appropriate for an app whose subject matter carries weight.
50% (full) = "look here." A circle is the strongest attractor shape. Reserved for the elements that demand immediate attention: the create action, the notification, the active state.
