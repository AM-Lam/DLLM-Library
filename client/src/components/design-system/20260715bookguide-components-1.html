Spacing & Core Components

The spacing foundation and the three essential components built on it — status chip, category chip, and book card. Each component is assembled entirely from tokens: colour, typography, radius, and the spacing scale below.

Foundations

Layout Spacing vs Component Anatomy
Layout spacing (this scale): space between elements the user perceives as separate — gap between cards, screen-edge padding, title-to-grid. These recur across contexts, risk drift if not centralised, and belong in the global scale.
Component anatomy (not this scale): space inside a single perceived unit — the 2px between a checkmark and its label inside one badge, a chip's vertical padding. Sub-4px values (1–3px) are always anatomy, never layout.
The test: a value belongs in the scale when it is (1) layout space between separate elements, (2) recurring across contexts, and (3) at risk of drift if not centralised. It stays local when it is internal construction of one unit, used in one place, already enforced by that component.
Components — 01
Status Chip
Renders a book's ItemStatus — one of five production enum values. Sits top-right of the cover photo overlay on every book card. Built from tokens: --radius-sm (4px), --type-caption (11px), plus internal anatomy padding. Each state carries a distinct colour + icon so it reads without relying on text alone.
States — 5 production enum values · bilingual
AVAILABLE 可借用 Available green
EXCHANGEABLE 可交換 Exchangeable blue
GIFT 贈送物 Gift violet
RESERVED 已預留 Reserved amber
TRANSFERRED 已轉讓 Transferred neutral ink
Colour logic: The three "active" states (AVAILABLE, EXCHANGEABLE, GIFT) use distinct functional hues so a user scanning a grid can tell borrow from swap from free at a glance. RESERVED (amber) signals "wait." TRANSFERRED (neutral ink) is deliberately muted — the book is gone, so its chip recedes. Memorial colours are never used for status.
Bilingual: The chip renders in the active app language. CJK from zh-HK.json, English from en.json, both keyed to the same ItemStatus enum. English labels run longer, so the chip is content-width, never fixed.

Components — 02
Category Chip
Renders a book's category — a free-form string from the category field. Two visual modes: neutral for ordinary categories, memorial-tinted for categories that match a known collective-memory event. The memorial tint is a presentation-layer lookup, not data.
Modes — neutral vs memorial
Neutral — the default for any category string
禁書政治散文紀實Hong Kong
Memorial-tinted — only for categories matching a known event
六四雨傘國安法
Why a lookup, not data: Categories are free-form strings (category: String!). The memorial tint is applied client-side: if the string matches an entry in a small memorial-events map, render the tinted variant; otherwise neutral.
Tags don't translate. A category is content, not UI copy. One fixed display form — whatever the curator entered — renders identically regardless of app language. 六四 stays 六四; "Hong Kong" stays "Hong Kong"; tags can be mixed-script. Only the surrounding UI swaps with the language toggle.

CJK floor watch: Category chips use 10px — safe only for 1–2 simple characters (六四, 禁書). A longer or stroke-dense category must render at 12px or truncate. The 10px floor is the exception the type system explicitly allows for chips.
Components — 03

The core browse unit. Assembled from a cover image, a 2-line name, one status chip, and up to two category chips (memorial-first, +N overflow). One component with three size variants — horizontal, grid, compact — sharing anatomy but differing in width and responsive behaviour.

Composition Rules
Category overflow: Show up to 2 chips. Memorial categories claim slots first (六四 before 散文), so the culturally significant tag always wins limited space. Remaining categories collapse to a +N count.
Status is singular, top-right. Exactly one status chip, always over the cover's top-right, backdrop-blurred for legibility on any image.
UI translates, content doesn't: The status chip swaps with app language. The book name and category tags do not — one fixed display form each. Because English UI labels run longer, the card never fixes chip width.
Title clamps to 2 lines. Noto Serif TC, weight 700. Longer names truncate — the full name lives on the detail page.
